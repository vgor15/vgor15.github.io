CAN Bus Lab

My Vector India dashboard: two LPC2129 boards on one CAN bus. Node A reads a speed pot, an MCP9700 temperature sensor and three switches, then sends frame 0x500. Node B decodes it onto a 16×2 LCD. This page replays the actual firmware logic, quirks included.

Node B · CAN2 receive interrupt (from the repo)

void CAN2_Rx_Handler(void) __irq
{
    v1.id  = C2RID;
    v1.dlc = ((C2RFS >> 16) & 0xF);
    v1.rtr = ((C2RFS >> 30) & 1);
    if (v1.rtr == 0) {
        v1.byteA = C2RDA;      /* data bytes 1-4 */
        v1.byteB = C2RDB;      /* data bytes 5-8 */
    }
    C2CMR = (1 << 2);      /* release receive buffer */
    flag = 1;
    VICVectAddr = 0;
}
