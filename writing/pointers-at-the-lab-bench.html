Pointers at the lab bench

As a lab coordinator at Vector India I helped students debug C every day, and pointers came up more than anything else. You learn a topic properly when you have to explain it ten different ways. These three pictures worked best.

Picture 1: memory is numbered boxes

Forget arrows at first. Memory is a long row of boxes, and every box has an address. A variable is a named box. A pointer is a box that holds another box's address.

int  x = 42;     /* box at 0x1000 holds 42      */
int *p = &x;     /* box at 0x1004 holds 0x1000  */

printf("%d\n", *p);   /* go to address 0x1000, read 42 */

& asks "what's your address?" and * says "go there". Once students wrote addresses next to their variables on paper, most of the confusion went away.

Picture 2: the pointer knows its step size

p + 1 doesn't add one byte. It moves one element, sizeof(*p) bytes. That single fact explains why arr[i] and *(arr + i) are the same thing, and why a char * and an int * walk the same memory differently.

Picture 3: the function that couldn't change anything

The classic: a swap(a, b) that swaps nothing. C passes copies, so the function swaps its own copies and throws them away. Pass the addresses and it works:

void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

swap(&x, &y);

The bugs I saw again and again

  • Uninitialised pointers. int *p; *p = 5; writes to wherever the garbage points. Initialise to NULL and check.
  • Returning the address of a local. It works in the demo, then the stack frame is gone.
  • Wrong malloc size. malloc(n) when you meant malloc(n * sizeof *p).
  • Forgetting the '\0'. A string of 5 letters needs 6 bytes.

Why this matters on hardware

On a microcontroller, pointers stop being abstract. A register is just a fixed address, and the device header turns it into a dereferenced pointer:

/* LPC2129: GPIO port 0 set register */
#define IOSET0  (*((volatile unsigned long *) 0xE0028004))

IOSET0 = (1 << 17);   /* LED on P0.17 */

Teaching made me precise. If I can't draw the boxes for a bug, I don't understand the bug yet.
