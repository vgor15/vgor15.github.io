# Vyom Island: how it's built

The whole website is one explorable low-poly island (`index.html` + `assets/js/island/`). Every section URL (`/about`, `/work`, `/machine`, `/bench`, `/contact`, `/now`, `/notes`, `/changelog`, `/writing`, `/lab`) is the same page, generated by `scripts/build.mjs` with `data-zone` set, so it opens at the matching place. Each one keeps its own title, description, JSON-LD and crawler-readable text.

Lab toys, posts, the résumé, `/board`, `/record` and the 404 Breakout stay as standalone pages. The island opens them in its reader (`?embed=1` hides their chrome), and their section links send visitors back to the island.

## Modules (`assets/js/island/`)
| File | Job |
|---|---|
| `main.js` | Boot, loader, input, camera, dialog, sheets, spatial UI, game loop; storybook fallback |
| `world.js` | Sky, sea, land, ground shader (fading grid + click shockwave), the eight places, the bus, day/night |
| `spawn.js` | `Spawner`: InstancedMesh for anything there are many of (trees, flowers, lamps, collectible chips), spring hover, picking |
| `post.js` | EffectComposer: MSAA render → SSAO → tilt-shift → high-threshold bloom → OutputPass, with a quality ladder |
| `materials.js` | Toy materials: MeshPhysicalMaterial with clearcoat (strong GPUs), Standard (mid), Lambert (weak) |
| `avatar.js` | People and VY-01, built from primitives |
| `panels.js` | What every place shows (shared by the island and the storybook) |
| `data.js` | Places, characters, dialogue, achievements, avatar options |
| `games.js`, `audio.js` | Packet Catch, Bit Flip; synthesized sound |

## Performance rules
- Text and the loader paint first. three.js and the world load as ES modules afterwards.
- Quality tier from the GPU (`../world/quality.js`):
  - **high:** SSAO, tilt-shift, bloom, HDRI and clearcoat.
  - **mid:** tilt-shift, bloom, HDRI and standard PBR.
  - **low:** plain render with Lambert materials.
- The pipeline steps down a level if the frame rate drops; the governor lowers the pixel ratio first.
- Shadows are baked: the map renders once (and again on day/night), and only big static objects cast. Characters use blob shadows.
- Instancing for everything repeated: one draw call per part.

## Accessibility
- The canvas is `aria-hidden`. Every action is a real button: the HUD, 3D tags, the talk card, dialog choices and the sheets.
- W A S D and the arrow keys move you, E talks, and Escape closes.
- Reduced motion snaps the camera and shows text at once.
- No WebGL2, or Plain view (`/?plain=1`), gets the storybook with the same content.
